## 1. Objective

The objective of this assignment is to evaluate the performance of a biometric authentication system using biometric feature vectors.

The provided dataset contains biometric feature vectors for 100 users. Each user has 10 biometric image samples:

- First 5 samples are used for enrollment/training.
- Remaining 5 samples are used for testing.
- Each biometric sample contains 144 features.

Two matching criteria are evaluated:

1. Euclidean Distance
2. Cosine Similarity

The following performance measures are computed:

- Genuine Distribution
- Impostor Distribution
- False Acceptance Rate (FAR)
- False Rejection Rate (FRR)
- Receiver Operating Characteristic (ROC)
- Equal Error Rate (EER)
- Decidability Index

---

## 2. Dataset

The dataset contains:

- **Number of users:** 100
- **Samples per user:** 10
- **Total samples:** 1000
- **Features per sample:** 144

The supplied CSV is stored in feature-oriented form:

```text
144 features × 1000 samples
```

The data is transposed in the notebook to obtain:

```text
1000 samples × 144 features
```

---

## 3. Enrollment and Test Split

For every user:

```text
Samples 1–5  → Enrollment
Samples 6–10 → Testing
```

Therefore:

```text
Enrollment samples = 100 × 5 = 500
Test samples       = 100 × 5 = 500
```

---

## 4. Template Generation

For every user, one representative biometric template is generated by taking
the average of the five enrollment feature vectors.

```text
Template(user) = Mean(5 enrollment feature vectors)
```

This results in:

```text
100 templates × 144 features
```

---

## 5. Biometric Matching

Each of the 500 test samples is compared against all 100 user templates.

Therefore:

```text
500 × 100 = 50,000 comparisons
```

These consist of:

```text
Genuine comparisons  = 500
Impostor comparisons = 49,500
```

A genuine comparison occurs when the test sample and template belong to the
same user. An impostor comparison occurs when they belong to different users.

---

## 6. Matching Criteria

### 6.1 Euclidean Distance

For feature vectors X and Y:

```text
d(X,Y) = sqrt(sum((Xi - Yi)^2))
```

For Euclidean distance:

```text
Smaller distance → Better match
Larger distance  → Worse match
```

### 6.2 Cosine Similarity

Cosine similarity is calculated as:

```text
Cosine Similarity = (X · Y) / (||X|| ||Y||)
```

For cosine similarity:

```text
Higher similarity → Better match
Lower similarity  → Worse match
```

The implementation calculates cosine distance and converts it to similarity:

```text
Cosine Similarity = 1 - Cosine Distance
```

## 8. FAR and FRR

### Euclidean Distance

```text
Distance <= Threshold → Accept
Distance > Threshold  → Reject
```

### Cosine Similarity

```text
Similarity >= Threshold → Accept
Similarity < Threshold  → Reject
```

False Acceptance Rate:

```text
FAR = False Acceptances / Total Impostor Attempts
```

False Rejection Rate:

```text
FRR = False Rejections / Total Genuine Attempts
```

FAR and FRR are evaluated over a range of thresholds and plotted in the
notebook.

---

## 9. ROC Curve

The ROC curve represents the trade-off between:

- False Acceptance Rate (FAR)
- Genuine Acceptance Rate (GAR)

where:

```text
GAR = 1 - FRR
```

For ROC computation, Euclidean distance is negated so that larger ROC scores
represent stronger matches.

### AUC Results

| Matching Criterion | AUC |
|---|---:|
| Euclidean Distance | **0.949556** |
| Cosine Similarity | **0.968943** |

Higher AUC indicates better overall discrimination.

---

## 10. Equal Error Rate (EER)

EER is the operating point where FAR and FRR are approximately equal.

A lower EER indicates better authentication performance.

| Matching Criterion | EER | Approximate Threshold |
|---|---:|---:|
| Euclidean Distance | **11.5889%** | 432.10 |
| Cosine Similarity | **8.2051%** | 0.97919 |

Therefore, cosine similarity achieves the lower EER.

---

## 11. Decidability Index

The decidability index measures the separation between genuine and impostor
score distributions.

```text
d' = |μgenuine - μimpostor|
     --------------------------------
     sqrt((σgenuine² + σimpostor²) / 2)
```

Higher values indicate better separation.

| Matching Criterion | Decidability Index |
|---|---:|
| Euclidean Distance | **1.762246** |
| Cosine Similarity | **1.925934** |

---

## 12. Overall Results

| Metric | Euclidean Distance | Cosine Similarity |
|---|---:|---:|
| AUC | 0.949556 | **0.968943** |
| EER (%) | 11.588889 | **8.205051** |
| Decidability Index | 1.762246 | **1.925934** |

For these metrics:

- Higher AUC is better.
- Lower EER is better.
- Higher Decidability Index is better.

Cosine Similarity performs better for all three metrics.

---

## 13. Conclusion

Both Euclidean Distance and Cosine Similarity provide discrimination between
genuine and impostor biometric attempts on the given dataset.

However, **Cosine Similarity performs better overall**.

It achieves:

- Higher AUC: **0.968943** vs **0.949556**
- Lower EER: **8.2051%** vs **11.5889%**
- Higher Decidability Index: **1.925934** vs **1.762246**

Therefore, based on the obtained experimental results, **Cosine Similarity
is the preferred matching criterion for this biometric authentication
experiment**.
